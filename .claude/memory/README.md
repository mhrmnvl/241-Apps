# Agent memory

Notes the assistant keeps about this project between sessions — what the user
has decided, how they want work shipped, and which repo docs have gone stale.

They live in the assistant's own directory on whichever machine it runs on,
which meant a laptop reinstall took them with it. Copied here so they survive
one, and so a second machine starts with the same context rather than
rediscovering it.

`MEMORY.md` is the index; each other file holds one fact.
